# Shared components (`src/presentation/components`, alias `@components`)

Import from the barrel: `import { Button, Card, Text } from "@components";` (`IconButton` comes from `@components/Icon`, `Skeleton` from `@components/Skeleton`).
All are dumb and theme-aware: they read `useKitTheme()` (Grafite tokens, see `theme.md`), never color literals. Flat surfaces only: `expo-blur` is gone from the kit. Every component accepts `testID` and derives part ids as `${testID}-<part>`. Components take **already translated** strings (labels, accessibility labels); screens call `t()`.
If you need a new 3rd-party UI element, **wrap it here first** (folder `Name/index.tsx` + `styles.ts` + `index.test.tsx` + `mocks/index.mocks.tsx`), export from `components/index.tsx`, and mock the lib in `tests/setup.tsx` if needed.

## Rules

- Screens use only kit components (lint-enforced, see Guardrails): no `react-native-paper` imports, no color literals, no hard-coded visual styling.
- Forms and selects open in a `BottomSheet` (or `SelectField`, which opens one).
- **Button rule (spec 008 FR 13):** one `Button.Primary` per screen or sheet; Cancel is never red (use `Button.Secondary` or the sheet's close button); `Button.Destructive` only for delete/leave/remove; `Button.Ghost tone="expense"` only for an edit form's "Delete ...".
- Components take translated strings; every pressable goes through `Touchable` (44px target, focus ring).
- Amounts are integer cents everywhere; format with `AmountText`, edit with `AmountInput`.

## Guardrails (spec 008 FR 39)

Two lint rules apply to `src/presentation` (`eslint/rules/presentation-guardrails.mjs`, `eslint/rules/no-restricted-imports.mjs`): (1) no color literals (`#hex`, `rgb()`, named colors; build tints with `toRgba` from `theme/constants/utils/rgba.ts`; only `theme/constants/**` is ignored, see `colorLiteralIgnores`); (2) screens may not import `react-native-paper` or raw RN visual primitives, only kit components. Unmigrated screens are listed in `migrationAllowList` in the same file; each of specs 010-014 removes its folders and 014 deletes the list. New screens must pass the rules.

## Deprecated adapters (FR 42)

Kept only so unmigrated screens compile, marked with a "Legacy, kept until spec 014" comment (no `@deprecated`: it fails `no-deprecated` lint on every touching commit): `Text.Headline/Label`, `Text` props `bold/color/textAlign`, `Button.Filled/Outlined/Text` and `customStyles`, `TextInput`, `Picker`, `DatePicker`, `Avatar.Large/Regular/Small`, `Card customStyles`, `IconButton size/color`. `Fab`/`FabGroup` were removed by 009. 010-014 remove them as screens migrate.

## Gallery

`app/(dev)/components.tsx` (route `/(dev)/components`, screen `src/presentation/screens/Dev/ComponentGallery`) renders every component in every state with a light/dark switch (`setThemeMode`, persists to the user config). `__DEV__` only: the `(dev)` layout redirects otherwise. Plain English strings (exempt from i18n). Add new kit components here.

## Test patterns

- Each component has `mocks/index.mocks.tsx` exporting `setup(props?)` that renders with defaults and returns handles.
- Assert styles with `StyleSheet.flatten(node.props.style)`.
- `useLocaleTag` (from `@presentation/i18n`) is globally mocked to `"en-US"` in `tests/setup.tsx`; so are `useTranslation` and `useTheme`.
- `react-native-reanimated` is mocked in `tests/setup.tsx` (add missing APIs there). `Screen` tests import `@shopify/flash-list/jestSetup` and mock `react-native-safe-area-context`.
- Paper components are mocked as `View`s: query by `testID`/label, not text.
